# Imagens da Tata Storys

O site está preparado para usar as fotografias reais/originais da Tata Storys sem alterar a pessoa no código.

## Arquivos esperados

Envie os três arquivos originais para esta pasta usando EXATAMENTE estes nomes:

- `thamires-editorial-original.jpeg` — fotografia/ensaio da Thamires usada no hero e portfólio;
- `thamires-corrida-original.jpeg` — fotografia da corrida usada no portfólio;
- `cinta-28-barbatanas-original.jpeg` — fotografia da cinta usada no guia visual e portfólio.

As imagens fornecidas têm 722 × 1600 px. O CSS usa `object-fit` apenas para enquadramento responsivo; o JavaScript não aplica filtros, retoque facial, alteração corporal ou transformação da pessoa.

## Guia de tamanho

As opções P, M, G e GG estão prontas em `fitlab.js`, mas as faixas em centímetros permanecem `null` até que a tabela oficial seja fornecida. Não invente medidas.
